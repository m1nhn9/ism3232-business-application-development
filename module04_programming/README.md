# Module 4: Python Programming Foundations

This module groups the programming labs from Weeks 5–8 with their tests and
generated data.

| Week | Topic | Main files |
| --- | --- | --- |
| 5 | Variables, types, and operators | `week5_lab.py` |
| 6 | Conditionals, loops, and dictionaries | `week6_lab.py`, `data/week6_summary.txt` |
| 7 | Functions, modules, and pytest | `business_rules.py`, `main.py` |
| 8 | Debugging and AI literacy | `week8_buggy.py`, `debug_log.md` |

## Run

From the repository root:

```sh
python -m module04_programming.main
python module04_programming/week6_lab.py
python module04_programming/week8_buggy.py
pytest -v module04_programming/tests
```

`week5_lab.py` is interactive and asks for a new quantity.
